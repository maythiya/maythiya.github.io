# maythiya.github.io

Personal portfolio site for **maythiya**, built as a lightweight static website and ready for GitHub Pages.

## Publish

1. Create a public GitHub repository named `maythiya.github.io`.
2. Upload or push this repository's `index.html`, `404.html`, and `.nojekyll` files to its `main` branch.
3. In **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/(root)`.
4. The site will be available at `https://maythiya.github.io` after deployment completes.

The site uses no server-side runtime, so it works directly with GitHub Pages.
